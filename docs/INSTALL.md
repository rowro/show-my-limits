# Установка Show My Limits

## Текущий статус

При первом запуске открывается «Подключение». Приложение ищет существующий mitmdump;
если его нет — предлагает установить официальный portable-пакет по кнопке. Отдельная установка Python не нужна.
Пакет размещается в собственном каталоге данных приложения, не заменяет системную установку
и проверяется по SHA-256 до распаковки. Поддерживаются macOS/Linux arm64 и x86_64, Windows x86_64.
Загрузка и распаковка проверены на macOS; остальные платформы требуют проверки.
На macOS нажмите «Установить сертификат»: системный диалог запросит разрешение администратора, затем импорт и доверие для HTTPS выполнятся автоматически. На Windows/Linux используется ручной импорт.

## macOS

Скопируйте Show My Limits.app в Applications, затем запустите.
В «Подключении» создайте сертификат и нажмите «Установить сертификат».
Подтвердите запрос администратора в системном окне macOS. Приложение не получает пароль.
Импорт выполняется через security add-certificates с запросом администратора.
Затем доверие настраивается через Security.framework из GUI-потока приложения.
macOS может запросить два подтверждения. После импорта проверяется присутствие именно этого сертификата.
Шаг завершается только после чтения сохранённого доверия HTTPS в домене Admin.
При повторной попытке уже импортированный сертификат используется без пересоздания.
При отмене или ошибке отметка готовности не устанавливается.
Ручной импорт остаётся доступным в «Установить вручную».
При первом запуске Local Capture разрешите Mitmproxy Redirector в сетевых расширениях macOS.
Перезапустите Claude после настройки доверия.
Для распространения за пределами своего Mac нужны Developer ID и notarization приложения/компонентов захвата.

## Windows

Используйте сборку для Windows; Tauri поддерживает установщики NSIS/MSI.
Откройте созданный Show My Limits сертификат → «Установить сертификат» → «Текущий пользователь» →
«Доверенные корневые центры сертификации». Если корпоративная политика требует другое хранилище,
потребуется администратор. Разрешения/драйвер Local Capture необходимо проверить на целевой Windows.
Для WebView требуется WebView2; его установку следует включить в релизный установщик Tauri.

## Linux

Установите зависимости Tauri/WebKitGTK для своего дистрибутива и поддержку системного трея.
Официальные ограничения Local Capture mitmproxy: Linux 6.8+, повышенные права для eBPF;
WSL для этого режима не поддерживается. В контейнере захват требует подходящей сетевой конфигурации.
Повышение прав дочернего компонента нужно испытать при запуске приложения из графического окружения:
для графического запроса пароля используется zenity через SUDO_ASKPASS. DEB рекомендует zenity; при его отсутствии приложение показывает команду установки. Проверка на реальной Ubuntu ещё требуется. Сам интерфейс не запускается от root, sudoers не изменяется.

Для Debian/Ubuntu сертификат обычно копируется как `.crt` в
`/usr/local/share/ca-certificates/`, затем выполняется `sudo update-ca-certificates`.
Show My Limits показывает путь к своему сертификату; браузер/рантайм может использовать отдельное хранилище.
Расположение трея, всплывающая панель и числовой значок зависят от рабочего окружения.

## Если нет показателей

Проверьте выбранный домен, профиль клиента, разрешение захвата и доверие CA именно в клиенте.
Запросы должны выполняться на том же компьютере, где работает захват.
Сервер должен отдавать `Anthropic-Ratelimit-Unified-*`; другие схемы квот не угадываются.
Show My Limits не строит цепочку с Proxyman/Charles и не меняет настройки системного прокси.

## Удаление

Сначала остановите захват и выйдите из Show My Limits, затем удалите приложение.
При необходимости отдельно удалите доверие к сертификату Show My Limits и его каталог данных.
Сертификаты других приложений и настройки Claude удалять не нужно.

## Ошибка «no user interaction was possible»

Старые сборки вызывали security через AppleScript с повышением прав. macOS может
не показать второе подтверждение настройки доверия из такого процесса.
В новой сборке используется нативный API внутри GUI-процесса. Если импорт ранее
успел выполниться, повторная попытка не требует удалять или пересоздавать сертификат.
Наличие сертификата в списке ещё не означает, что доверие настроено.

Ошибка -61 (Write permissions error) означает, что обычный GUI-процесс попытался
записать сертификат в системную связку без повышенных прав. Новая реализация
повышает права только для импорта; диалог доверия остаётся внутри GUI-приложения.
Если сертификат уже импортирован, этап с повышением прав пропускается.


После каждого включения перехватчика обязательно полностью перезапустите клиент.
На macOS выйдите из Claude через ⌘Q и откройте его заново: закрытия окна недостаточно.
В терминале или IDE завершите текущую сессию Claude Code и запустите новую.
Приложение показывает эту подсказку до первого ответа с лимитами текущего запуска
перехватчика. Старый снимок её не скрывает; после успешного ответа она не появляется
снова просто из-за давности данных.


После полной настройки приложение само запускает перехватчик при каждом открытии.
Чтобы запускать и само приложение после входа в ОС, откройте шестерёнку и включите
«Запускать вместе с ОС». На macOS сначала держите приложение в «Программах».
Включение переключателя не требует изменять настройки Claude.

## Доверие сертификату в Ubuntu / Debian

Просмотрщик сертификатов может не поддерживать импорт в системное хранилище. В мастере Show My Limits скопируйте команды установки доверия: публичный CA копируется с расширением `.crt` в `/usr/local/share/ca-certificates/`, затем запускается `sudo update-ca-certificates`. После успешного выполнения нажмите «Я добавил доверие» и перезапустите клиент. Имя файла `mitmproxy-ca-cert.cer` и имя сертификата `limits-mitmproxy` — разные поля. Закрытый ключ импортировать не нужно.

Для standalone-сборок готовность проверяется идентификатором запуска и свежим heartbeat, так как загрузчик и рабочий процесс могут иметь разные PID. Остановить можно и во время запуска; ожидание готовности ограничено 90 секундами.

### Windows: оставшиеся процессы старых версий

В 0.1.7 остановка и выход завершают принадлежащее приложению дерево перехватчика, включая воркеры. Если от старой версии уже остались процессы, новая версия не будет автоматически присваивать или завершать их по одному имени. Выйдите из старого приложения и завершите именно ранее найденные его процессы в Диспетчере задач, проверив расположение файла. Не завершайте процессы Throne и другие перехватчики по общему имени. Сертификат переустанавливать не нужно.

Проверьте три случая: «Остановить», «Выйти», аварийное закрытие самого Show My Limits. После них его загрузчик/воркер не должны оставаться. Сосуществование одновременно активного Windows local capture и TUN зависит также от сетевого движка; исправление очистки процессов само по себе не доказывает совместимость режимов.
