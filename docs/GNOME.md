# GNOME / Ubuntu 24.04

Первая версия расширения рассчитана на **GNOME 46** — стандартную оболочку Ubuntu 24.04. Для других версий и оболочек остаётся обычный трей приложения.

1. Установи Show My Limits **0.1.5+**. При первом подключении расширение GNOME ставится автоматически.
2. Для обновления с 0.1.4 открой настройки → **Панель GNOME** → **Обновить расширение**.
3. Нажми **Выйти из сеанса…**: Ubuntu покажет своё подтверждение выхода. После входа приложение запустится один раз для завершения настройки и само включит расширение. Вводить команды не нужно.

Если Shell уже распознал файлы, расширение может включиться сразу. Первая локальная установка и обновление кода часто требуют нового сеанса GNOME. Обычный трей остаётся доступен до подключения расширения.

**Левый клик** по процентам раскрывает лимиты, прогресс, расход и время сброса прямо под панелью. **Правый клик** открывает меню приложения и настроек. Панель использует тему GNOME; настройка оформления в приложении управляет его собственным окном.

Обычный трей скрывается, пока расширение получает данные. Если его отключить или оно перестанет отвечать, трей вернётся максимум через 16 секунд. После выхода из приложения расширение показывает «—» и позволяет запустить его снова. Для AppImage может потребоваться ручной запуск файла.

Обновление расширения: нажми «Обновить расширение», затем используй кнопку выхода из сеанса, чтобы GNOME перечитал его код. Версия расширения обновляется отдельно от версии приложения; установленные файлы не заменяются без нажатия кнопки.

Отключение:

```sh
gnome-extensions disable show-my-limits@rowro.github.io
```

При необходимости после отключения удали только каталог расширения:
`~/.local/share/gnome-shell/extensions/show-my-limits@rowro.github.io`.

## Проверка в виртуалке

- После установки/включения в панели один индикатор, без дубликата обычного трея.
- `./claude --ipv4 --scenario normal --count 1` при сервере `httpbingo.org`: **65%** за 5 часов, **58%** за 7 дней.
- Левый клик открывает лимиты сразу; правый — отдельное меню; клик снаружи закрывает поповер.
- Проверь настройки, выход и запуск приложения через меню расширения.
- Отключи расширение: обычный трей должен вернуться. Включи снова: дубликат должен исчезнуть.
- После выхода/входа в сеанс нет второго индикатора и ошибок расширения.

## Для разработчиков

Исходники: `integrations/gnome/`. Расширение не запускает перехватчик и не читает настройки Claude. Оно общается с приложением через пользовательскую D-Bus-шину: `io.github.rowro.ShowMyLimits`, объект `/io/github/rowro/ShowMyLimits`, интерфейс `io.github.rowro.ShowMyLimits1`.

Контракт v1: `GetState → JSON`, `Heartbeat(uint32 protocol) → bool`, `Detach`, `OpenWindow("overview"|"settings")`, `Quit`. JSON содержит только время, фазу подключения, признак завершённой установки/ошибки и квоты текущего сервера. Пути, настройки, ключи CA, пароли и содержимое запросов не передаются. Совместимый heartbeat раз в 2 секунды удерживает 15-секундную аренду индикатора; исчезновение расширения восстанавливает стандартный трей.

Проверки модели выполняются через `npm test`. Release CI проверяет реальный D-Bus-мост в изолированном профиле через Xvfb. Это не заменяет проверку поведения GNOME Shell в виртуалке.
