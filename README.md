# Show My Limits

Компактный монитор лимитов Claude в системном трее. **Tauri 2 + TypeScript + Rust + mitmproxy**.
Новый самостоятельный проект, не изменяющий установленный Claude Limits и его сертификат.

## Что уже есть

- Остаток пятичасового лимита в строке меню macOS; числовой значок в Windows/Linux.
- Компактная панель: 5 часов, 7 дней, расход, остаток, время сброса, давность данных.
- Системная, светлая и тёмная темы.
- Настраиваемый список серверов, любой путь запроса; данные определяются по `Anthropic-Ratelimit-Unified-*`.
- Профили Desktop, локального Claude Code и IDE. Разные организации хранятся отдельно; проценты не суммируются.
- Автоматический запуск своего перехватчика при открытии настроенного приложения. Кнопка остановки остаётся доступной; после ручной остановки захват не перезапускается до следующего открытия приложения или нажатия «Запустить».
- Необязательный запуск вместе с ОС: переключатель в настройках, по умолчанию выключен.
- Мастер подготовки отдельного сертификата Show My Limits. На macOS доверие настраивается по кнопке через системный запрос администратора; ручной импорт также доступен.
- Другие HTTPS-прокси не захватываются. Обнаруженный системный прокси блокирует запуск вместо скрытого построения цепочек.
- Устаревший снимок не отображается как актуальный процент. Ошибки отменённых соединений не выдаются за недоверие к CA.

## Разработка

Нужны Node.js 22.12+, Rust, системные зависимости Tauri. mitmdump можно установить из раздела «Подключение» или использовать существующую установку.

```sh
cd ~/webdev/show-my-limits
npm install
npm run tauri dev
```

Отдельный предпросмотр интерфейса:

```sh
npm run dev
# http://localhost:1420/?demo=1&theme=light
# http://localhost:1420/?demo=1&theme=dark
```

В браузере захват не запускается. Параметр `demo=1` показывает явно помеченные вымышленные показатели.

```sh
npm test
python3 -m unittest discover -s proxy -v
npm run test:rust
npm run build
npm run tauri build
```

Установщики собираются **на соответствующей ОС**. Локальная сборка на Mac не означает проверку на Windows/Linux.

## Первое подключение

1. Настройки → добавить домен/URL сервера и выбрать клиент.
2. Подключение → проверить mitmdump → создать сертификат.
3. Открыть сертификат и добавить доверие в ОС. Затем полностью перезапустить клиент.
4. Запустить захват и отправить сообщение в Claude. Статус перехватчика и давность полученных показателей отображаются отдельно.

Домен фильтруется и в mitmproxy, и в обработчике. Путь `/claude/v1/messages` не зашит.
Если сервер не отдаёт unified-заголовки (например, при иной схеме API-биллинга), Show My Limits не вычисляет квоту из числа сообщений.
Remote SSH/облачный агент требует захвата там, где действительно выполняются запросы.

## Упаковка перехватчика

mitmdump ищется по явно заданному пути, в каталоге данных приложения, ресурсах сборки, PATH и стандартных каталогах Homebrew/macOS. Если найден существующий файл, повторная установка не выполняется.
Для самостоятельного пакета положите **проверенный standalone-дистрибутив** нужной ОС/архитектуры внутрь:

```sh
npm run prepare:helper -- /path/to/standalone/mitmdump
# или каталог полного standalone-дистрибутива
npm run prepare:helper -- /path/to/standalone/distribution
npm run tauri build
```

Обычный Python-скрипт `mitmdump` из venv не является самостоятельным бинарником.
Для релиза надо проверить также драйвер/сетевое расширение, подпись, установку CA и удаление на чистой ОС.
Текущий проект — рабочая основа приложения; автоматически проверенные установщики без внешних зависимостей ещё не выпущены.

## Данные и безопасность работы

Настройки и состояние лежат в каталогах приложения `dev.clim.desktop`, получаемых через Tauri Path API. Внутренний идентификатор сохранён после переименования, чтобы сохранить настройки и сертификат.
`settings.json` здесь принадлежит **Show My Limits**, не Claude. Сетевые настройки ОС и конфигурация Claude не меняются.

`proxy/state.json` содержит время обновления, квоты и диагностическую категорию.
Тексты сообщений, заголовки авторизации, cookies и исходные organization ID не сохраняются.
Для разграничения организаций используется хеш сервера и organization ID, если он присутствует в ответе.
Для одной организации с несколькими независимыми квотами понадобятся дополнительные явные профили.

Сертификат и его закрытый ключ генерируются локально в каталоге Show My Limits; их нельзя включать в репозиторий или раздаваемый пакет.
Наличие сертификата на диске не означает, что клиент ему доверяет.

## Структура

- `src/` — интерфейс и форматирование лимитов.
- `src-tauri/src/engine.rs` — настройки, дочерний процесс, сертификат и состояние.
- `src-tauri/src/quota.rs` — модель показателей и правила свежести.
- `proxy/limits_addon.py` — универсальный обработчик заголовков без записи трафика.
- `docs/INSTALL.md` — установка и особенности ОС.

Первое правило выпуска: не заменять работающий перехватчик экспериментальной маршрутизацией. Новые сборки тестируются отдельно.

## Установка по кнопке и первый запуск

Пока не готовы перехватчик, сертификат, доверие, сервер и клиенты, приложение открывает
«Подключение». Главная страница также предлагает продолжить подключение.
На macOS кнопка «Установить сертификат» добавляет CA в системную связку с доверием для HTTPS через штатный запрос администратора. Пароль не передаётся в приложение. Успешное завершение команды сохраняет готовность шага; отмена или ошибка её не устанавливают. Ручной способ остаётся доступным. Фактическое доверие со стороны клиента проверяется новым ответом Claude.

Если mitmdump не найден, кнопка установки скачивает официальный portable-пакет 12.3.1
с downloads.mitmproxy.org в каталог данных приложения. Python и Homebrew не нужны.
Перенаправления отключены, TLS и закреплённая SHA-256 проверяются до распаковки.
Загрузка не запускает перехват, не заменяет системную установку и не добавляет доверие CA.
Поддержаны архивы macOS/Linux arm64 и x86_64, Windows x86_64.
Реальная загрузка и распаковка проверены на macOS; Windows/Linux требуют проверки.
Для обновления закреплённой версии нужно обновить имена и хеши в installer.rs.

src/assets/show-my-limits.svg — единый исходник логотипа интерфейса и иконок сборки.

Установка CA на macOS выполняется отдельным действием пользователя через
Security.framework внутри основного GUI-потока приложения. Сертификат добавляется
в системную связку, доверие ограничено политикой HTTPS. После операции приложение
считывает сохранённые настройки доверия для этого сертификата в домене Admin;
только результат TrustRoot позволяет завершить шаг. Повторный импорт того же
сертификата обрабатывается без ошибки дубликата. Пароль вводится только в диалоге macOS.
Импорт выполняется отдельно: security add-certificates с правами администратора через системный диалог AppleScript.
Настройка доверия выполняется только через Security.framework в GUI-процессе приложения;
в привилегированной оболочке доверие не настраивается. macOS может запросить два подтверждения.
До и после импорта сертификат сверяется по полному DER в системной связке; имя само по себе не используется для сравнения.
Автоматическая установка CA при запуске приложения отсутствует. Автоматический старт перехватчика выполняется только после завершённой настройки.


После каждого включения перехватчика обязательно полностью перезапустите клиент.
На macOS выйдите из Claude через ⌘Q и откройте его заново: закрытия окна недостаточно.
В терминале или IDE завершите текущую сессию Claude Code и запустите новую.
Приложение показывает эту подсказку до первого ответа с лимитами текущего запуска
перехватчика. Старый снимок её не скрывает; после успешного ответа она не появляется
снова просто из-за давности данных.


Popover UI: the panel starts hidden and opens from its tray item. Clicking outside or clicking the tray item again hides it. On macOS native window movement is disabled; the frontend has no drag regions. Settings open from the header gear. The server row shows the last-update age, and each reset is displayed on one line. The certificate authorization dialog temporarily keeps its parent panel available.

## Экран подключения и запуск

Табов нет. Пока не готовы mitmdump, сертификат, доверие, сервер и клиенты, отображается
только мастер подключения. Сервер и клиенты задаются в нём же. Последнее успешное
действие запускает захват и открывает основной экран лимитов. При ошибке запуска
мастер остаётся доступен для исправления и повторной попытки.

При последующих открытиях настроенное приложение запускает перехватчик автоматически
и остаётся в трее. Незавершённая настройка блокирует автоматический старт.
Шестерёнка переключает основной экран и настройки; домик возвращает к лимитам.

«Запускать вместе с ОС» регистрируется через официальный tauri-plugin-autostart:
LaunchAgent на macOS, стандартный механизм автозапуска на Windows/Linux.
Значение читается из ОС, переключатель применяется сразу. Само наличие настройки
не включает автозапуск. На macOS сначала переместите приложение в «Программы», затем
включите переключатель. После перемещения повторно выключите/включите его для нового пути.
Проверка реального входа в ОС выполняется отдельно; при разработке автозапуск не включался.

## Применение настроек

Серверы и клиенты доступны для редактирования при активном захвате. «Сохранить» закреплено в футере настроек. После проверки и записи новых параметров приложение останавливает только собственный перехватчик, ждёт его завершения и запускает с новыми параметрами. Ошибочные параметры не останавливают текущий захват. Тема и выбор профиля не требуют перезапуска; остановленный вручную захват остаётся остановленным. При ошибке повторного запуска настройки сохраняются, а ошибка показывается пользователю.

Ручной путь к mitmdump оставлен только как запасной вариант на этапе подключения, если автоматический поиск не нашёл установленную версию. Обычные настройки этого поля не содержат.

## Распространение macOS

Для ранних тестовых выпусков без Apple Developer Program можно отдавать сборку напрямую. Такая сборка не имеет доверенного Developer ID и notarization: macOS может блокировать первый запуск. Пользователь самостоятельно разрешает его для конкретного приложения в «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть», если доверяет источнику. Корпоративная политика может запрещать исключение. DMG, ZIP или Homebrew сами по себе не заменяют подпись и notarization.

Для публичного выпуска с обычным первым запуском нужен Developer ID Application и notarization через Apple; это требует платного членства Apple Developer Program. Бесплатный аккаунт и локальная ad-hoc подпись не заменяют Developer ID. Сборка из исходников на компьютере пользователя — отдельный вариант для разработчиков.

Подпись приложения и CA перехватчика решают разные задачи: notarization не отменяет установку локального сертификата и системные разрешения захвата. Их пользователь подтверждает отдельно.

Источники: https://developer.apple.com/programs/ и https://support.apple.com/en-us/102445.

Новые CA создаются с Common Name `limits-mitmproxy` и организацией `Show My Limits`, чтобы их было легко найти в системном хранилище. Имена файлов mitmproxy сохраняются. Генерация выполняется штатным `CertStore.create_store` в отдельном временном каталоге; готовый каталог публикуется только после успешного завершения. Существующие сертификаты и ключи не заменяются и не переименовываются автоматически.

## Сборки и обновления

Репозиторий: https://github.com/rowro/show-my-limits. GitHub Actions собирает macOS ARM/Intel, Windows x64 и Linux x64 и складывает установщики в черновик GitHub Release. Подробности: [docs/RELEASING.md](docs/RELEASING.md). Приложение проверяет опубликованный `latest.json` и устанавливает подписанное обновление по кнопке в настройках. Для Linux обновление внутри приложения первоначально поддерживается для AppImage; .deb устанавливается вручную.
