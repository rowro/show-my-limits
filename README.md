# Show My Limits

Лимиты Claude — в системном трее, без открытия отдельного окна.
Приложение показывает остаток пятичасового и недельного лимита, расход и время следующего сброса.

- Процент оставшегося пятичасового лимита в трее.
- Компактная панель с лимитами и временем последнего обновления.
- Светлая, тёмная и системная темы.
- Автозапуск вместе с системой и проверка обновлений.
- Поддержка своего сервера и дополнительных процессов для расширений IDE.

## Установка

Скачайте сборку для своей системы в [Releases](https://github.com/rowro/show-my-limits/releases):

| Система | Файл |
| --- | --- |
| macOS Apple Silicon | `darwin-aarch64.dmg` |
| macOS Intel | `darwin-x86_64.dmg` |
| Windows x64 | `windows-x86_64-setup.exe` |
| Linux x64/ARM64 | `.AppImage` или `.deb` |

На macOS переместите приложение в «Программы». Текущие сборки без подписи Apple Developer ID и нотариализации: при первом запуске может потребоваться разрешение в «Системные настройки → Конфиденциальность и безопасность».

Сборки Windows и Linux пока требуют проверки установки и перехвата на реальных устройствах. На Linux для перехвата нужны ядро 6.8+ и повышенные права; графический запрос этих прав пока не реализован.

## Первый запуск

1. Пройдите мастер подключения: установите перехватчик, создайте сертификат и настройте доверие к нему. Python и Homebrew устанавливать не нужно.
2. Укажите домен или URL сервера Claude. По умолчанию отслеживаются процессы `Claude` и `claude`; дополнительные можно добавить в настройках.
3. После включения перехватчика полностью перезапустите Claude Desktop, терминальную сессию Claude Code или IDE. На macOS выйдите из Desktop через `⌘Q` — закрытия окна недостаточно.
4. Напишите сообщение в чат. После ответа сервера лимиты появятся в приложении.

Панель открывается по клику на значок в трее и скрывается при клике вне окна. Настройки доступны через шестерёнку.

## Как появляются данные

Show My Limits читает заголовки лимитов из ответов выбранного сервера через локальный HTTPS-перехватчик mitmproxy. Для этого нужен локальный сертификат, которому доверяет ваш клиент. Сертификат и его закрытый ключ создаются на вашем компьютере.

Сообщения, токены авторизации и cookies не сохраняются. Настройки и последние показатели хранятся локально. Конфигурация Claude и настройки системного прокси не меняются.

Показатели обновляются с новыми ответами Claude. Если сервер не передаёт заголовки `Anthropic-Ratelimit-Unified-*`, приложение не сможет показать лимиты. Запросы должны выполняться на том же компьютере, где запущен перехватчик; удалённые агенты и сессии Remote SSH им не охватываются.

## Обновления

Приложение проверяет обновления при запуске. Проверить вручную и установить новую версию можно в настройках. Пакеты обновлений проверяются по цифровой подписи.

На Linux обновление внутри приложения поддерживается для AppImage; для DEB нужно скачать и установить новый пакет.
